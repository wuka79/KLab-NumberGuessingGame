
# K LAB — Number Guessing Game

The first official game developed by K LAB.

A desktop number guessing game built with Python and Tkinter, featuring a clean dark interface and interactive gameplay.

## Features

- Three difficulty levels
- Random number generation
- Score tracking
- Player records and persistent data
- Interactive sound effects
- Animated win and lose feedback
